RelationshipMatrices.jl

Kinship & Matrices

High-performance computation of relationship matrices for quantitative genetics. Provides parallelized, bit-packed Genomic Relationship Matrix (GRM) calculation with hardware popcount acceleration, pedigree-based numerator relationship matrices (A, A−1, inbreeding coefficients) via Henderson's sparse methods, and realized IBD tracking.

Documentation · Source

FisherWright.jl

Population Simulation

Simulates mutation-drift equilibrium in finite Fisher-Wright populations. Features dynamic mutation tracking, multi-chromosome recombination maps, and generational burn-in to generate realistic founder haplotypes and linkage disequilibrium structures.

Documentation · Source

BnGStructs.jl

Genomic Structures

Foundational data structures for storing and manipulating SNP haplotypes and genotypes. Implements compact BitMatrix representations for haplotype-major and individual-major layouts, species and chromosome metadata, continuous and threshold trait definitions, and fast true breeding value (TBV) evaluations.

Documentation · Source

Breeding.jl

Breeding & Selection

Breeding program simulation and genomic prediction utilities based on pedigree and SNP genotype data. Provides tools for selection cycles, customizable mating schemes, and genomic estimated breeding value (GEBV) prediction.

Source

BnGsim.jl

Workflows & Pipelines

Simulation workflows and pipelines built upon the JuliaBnG ecosystem. Coordinates founder population sampling, multi-generation breeding scenarios, and quantitative genetic experiments by integrating BnGStructs, FisherWright, and RelationshipMatrices.
