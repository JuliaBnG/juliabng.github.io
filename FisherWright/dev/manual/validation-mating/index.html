Validation of the mating schemes

docs/src/validation/scripts/validate-mating.sh compares the mating schemes of FisherWright with a matched model in SLiM 5 (validate-mating.slim), in which each scheme is written anew in Eidos and runs on SLiM's own meiosis and pedigree. Where the expected heterozygosity is known exactly, it is compared with that as well.

Model. Both simulators run $N = 40$ diploid individuals for 30 discrete generations without mutation, from a polymorphic start: each of $L = 1{,}000$ sites, on 20 chromosomes of 50 bp and 1 Morgan, is carried by each haplotype with probability ½. In SLiM the model is nonWF with explicit reproduction: every generation, the offspring of each population are created from a table of sire and dam drawn by the scheme, and the parents then die. SLiM has no sexes here: as in FisherWright, the roles of sire and dam are assigned anew to the parents of every generation (Bernoulli(½) per individual, redrawn until both sexes, or the breeders a design needs, are present; or a fixed number of males, a random subset). Relatives are judged on SLiM's pedigree IDs (pedigreeParentIDs, pedigreeGrandparentIDs), with the starting population of unknown parents, as in FisherWright. Crossovers differ slightly: 49 gaps of 1/49 per chromosome in SLiM, a Poisson(1) number at uniform positions in FisherWright; this changes the linkage between sites, but not the expectations compared.

Statistics. At the end, Σ2pq per site over the $2N$ haplotypes (with replacement), the observed heterozygosity $H_{obs}$, and the number of offspring of relatives that could not be avoided within 100 draws (related_matings, summed over the run). Each simulator runs 4,000 replicates per scheme (SLiM: 40 processes of 100 populations); the table gives mean ± SE, the z-score of the difference between the simulators, and for the first six schemes the exact expectation, from the recursion of the heterozygosity within ($H_W$) and between ($H_B$) individuals,

\[H_B' = (1 - a)H_B + \tfrac{a}{2}H_W, \qquad H_W' = (1 - \sigma)H_B + \tfrac{\sigma}{2}H_W,\]

with $a$ the probability that two genes of different offspring come from one parent (from the closed forms under Family sizes) and $\sigma$ the selfing rate; $\Sigma 2pq = H_W/(2N) + (1 - 1/N)H_B$ and $H_{obs} = H_W$. Avoidance of relatives has no such reference, which is why it is compared with an independent implementation.

Resolution. The standard errors are 0.04% to 0.17% of the means. A difference between the simulators of 3.5 combined SE corresponds to an error of about 0.5% (random mating) to 1% (the hierarchical design) in the effective size over the 30 generations. The schemes themselves are far apart: avoiding half-sib matings raises $H_{obs}$ from 0.3455 to 0.3537, about 40 SE.

The run takes about 10 minutes on 16 cores:

docs/src/validation/scripts/validate-mating.sh path/to/slim outdir 4000 2026 16

To run some schemes only, list them in SCHEMES, as for the check of cousin avoidance below:

SCHEMES="avoid_cousin5" docs/src/validation/scripts/validate-mating.sh path/to/slim outdir 16000 11 24

Reading the results

Across the 2 × 9 schemes and 2 × 19 non-degenerate comparisons between the simulators, the largest $|z|$ is 1.77 (rm5, seed 7, both statistics). FisherWright is within $|z| \le 1.66$ of the exact expectation for the six schemes that have one. Neither simulator is systematically above the other or above the expectation. Where no offspring of relatives can be forced, both report none: with about 20 females, an unrelated dam is always found within 100 draws. Under cousin avoidance with five sires, nearly every pair is related after a few generations, and about 237 of the 1,200 offspring per run are forced in both simulators.

One pattern prompted a further run. In both seeds, cousin avoidance left FisherWright slightly more heterozygous than SLiM (z between 1.14 and 1.55, combined over the seeds about 1.9) with slightly fewer forced matings. Several schemes and statistics were compared, so this is unremarkable as a single result, but its consistency across seeds called for a check. Rerun alone with four times the replicates (seed 11, above), the differences are −0.61, −0.38 and +0.17 SE, so the pattern was noise.

Within the resolution given above, FisherWright's implementations of the mating schemes agree with SLiM's pedigree and meiosis and, where the expectation is known, with theory. Linkage was not compared: the two crossover models differ (49 discrete gaps against continuous positions).

Scripts

// Matched SLiM model for the mating schemes of FisherWright
// (docs/dev/roadmap.md, validation 4). An independent implementation of
// each scheme in Eidos, with SLiM's own meiosis and pedigree: K replicate
// populations of N individuals, discrete generations (nonWF, parents die
// after reproducing), sex not inherited (a sexless model; the roles of
// sire and dam are assigned anew in every generation, as in FisherWright),
// no mutation. The start is polymorphic: each of the L = 1,000 sites, on 20
// chromosomes of 50 bp and 1 Morgan, is carried by each haplosome with
// probability 1/2. After NT generations each population reports Σ2pq / L,
// the observed heterozygosity and the number of offspring of relatives
// that could not be avoided.
//
// Constants (slim -d): SCHEME (string), N, NT (generations), K, and the
// seed with -s.
// Schemes: "rm" RandomMating(); "rm5" RandomMating(nmale = 5);
// "fsgamma" FamilySize(dams = 1.0, sires = :random, nmale = 10);
// "hier" Hierarchical(4, 3); "mono" Monoecious(); "self" Monoecious(selfing
// = 0.5); "avoid_half" AvoidRelatives(RandomMating(); level = :halfsib);
// "avoid_cousin5" AvoidRelatives(RandomMating(nmale = 5); level = :cousin);
// "avoid_mono" AvoidRelatives(Monoecious(selfing = 0); level = :fullsib).

initialize() {
    initializeSLiMModelType("nonWF");
    initializeSLiMOptions(keepPedigrees = T);
    defineConstant("L", 1000);
    defineConstant("MAXTRIES", 100);
    initializeMutationRate(0.0);
    initializeMutationType("m1", 0.5, "f", 0.0);
    m1.convertToSubstitution = F;
    initializeGenomicElementType("g1", m1, 1.0);
    initializeGenomicElement(g1, 0, L - 1);
    // 49 gaps per chromosome at 1/49 each (1 Morgan), 0.5 between them.
    ends = integer(0);
    rates = float(0);
    for (c in 0:19) {
        ends = c(ends, (c < 19) ? 50 * c + 48 else 50 * c + 49);
        rates = c(rates, 1 / 49);
        if (c < 19) {
            ends = c(ends, 50 * c + 49);
            rates = c(rates, 0.5);
        }
    }
    initializeRecombinationRate(rates, ends);
    defineGlobal("FORCED", integer(K));
}

// Sex of n parents: Bernoulli(1/2), redrawn until there are at least minm
// males and minf females; or exactly nm males, a random subset (nm > 0).
function (integer)drawSex(integer$ n, integer$ nm, integer$ minm, integer$ minf) {
    if (nm > 0) {
        sex = integer(n);
        sex[sample(0:(n - 1), nm)] = 1;
        return sex;
    }
    do sex = rbinom(n, 1, 0.5);
    while (sum(sex) < minm | n - sum(sex) < minf);
    return sex;
}

// Whether two individuals are related at level 1 (the same two parents),
// 2 (a parent in common) or 3 (a parent or grandparent in common); unknown
// parents (-1) match nothing.
function (logical$)related(object<Individual>$ a, object<Individual>$ b, integer$ level) {
    pa = a.pedigreeParentIDs;
    pb = b.pedigreeParentIDs;
    pa = pa[pa >= 0];
    pb = pb[pb >= 0];
    if (level == 1)
        return (size(pa) == 2 & size(pb) == 2 & all(sort(pa) == sort(pb)));
    if (size(setIntersection(pa, pb)) > 0)
        return T;
    if (level == 2)
        return F;
    ga = a.pedigreeGrandparentIDs;
    gb = b.pedigreeGrandparentIDs;
    ga = ga[ga >= 0];
    gb = gb[gb >= 0];
    return size(setIntersection(ga, gb)) > 0;
}

// One of 0:(n-1) other than p, uniformly.
function (integer$)other(integer$ p, integer$ n) {
    q = sample(0:(n - 2), 1);
    return (q >= p) ? q + 1 else q;
}

// Sire and dam (indices into the parents) of each of no offspring.
function (integer)matings(object<Subpopulation>$ pop, integer$ no, integer$ k) {
    inds = pop.individuals;
    n = size(inds);
    sire = integer(no);
    dam = integer(no);
    forced = 0;
    if (SCHEME == "rm" | SCHEME == "rm5" | SCHEME == "avoid_half" | SCHEME == "avoid_cousin5") {
        nm = (SCHEME == "rm5" | SCHEME == "avoid_cousin5") ? 5 else 0;
        level = (SCHEME == "avoid_half") ? 2 else ((SCHEME == "avoid_cousin5") ? 3 else 0);
        sex = drawSex(n, nm, 1, 1);
        males = which(sex == 1);
        females = which(sex == 0);
        for (i in 0:(no - 1)) {
            s = sample(males, 1);
            d = sample(females, 1);
            if (level > 0) {
                tries = 1;
                while (related(inds[s], inds[d], level)) {
                    if (tries >= MAXTRIES) {
                        forced = forced + 1;
                        break;
                    }
                    d = sample(females, 1);
                    tries = tries + 1;
                }
            }
            sire[i] = s;
            dam[i] = d;
        }
    } else if (SCHEME == "fsgamma") {
        sex = drawSex(n, 10, 1, 1);
        males = which(sex == 1);
        females = which(sex == 0);
        // Offspring among the dams: multinomial with Gamma(1) weights.
        w = rgamma(size(females), 1.0, 1.0);
        dam = sample(females, no, replace = T, weights = w);
        // The sire of every dam: uniform among the males.
        sireof = integer(n);
        sireof[females] = sample(males, size(females), replace = T);
        sire = sireof[dam];
    } else if (SCHEME == "hier") {
        // 4 sires, 12 dams, 3 dams per sire, equal dam families.
        sex = drawSex(n, 0, 4, 12);
        sires = sample(which(sex == 1), 4);
        dams = sample(which(sex == 0), 12);
        q = asInteger(floor(no / 12));
        cnt = rep(q, 12);
        r = no - 12 * q;
        if (r > 0)
            cnt[sample(0:11, r)] = q + 1;
        slot = sample(rep(0:3, 3), 12);   // the sire of each dam
        j = 0;
        for (d in 0:11) {
            if (cnt[d] > 0) {
                for (c in 1:cnt[d]) {
                    sire[j] = sires[slot[d]];
                    dam[j] = dams[d];
                    j = j + 1;
                }
            }
        }
    } else if (SCHEME == "mono" | SCHEME == "self" | SCHEME == "avoid_mono") {
        selfing = (SCHEME == "self") ? 0.5 else ((SCHEME == "avoid_mono") ? 0.0 else -1.0);
        for (i in 0:(no - 1)) {
            p = sample(0:(n - 1), 1);
            if (selfing < 0)
                q = sample(0:(n - 1), 1);
            else if (runif(1) < selfing)
                q = p;
            else
                q = other(p, n);
            if (SCHEME == "avoid_mono" & q != p) {
                tries = 1;
                while (related(inds[p], inds[q], 1)) {
                    if (tries >= MAXTRIES) {
                        forced = forced + 1;
                        break;
                    }
                    q = other(p, n);
                    tries = tries + 1;
                }
            }
            sire[i] = p;
            dam[i] = q;
        }
    } else
        stop("unknown SCHEME " + SCHEME);
    FORCED[k] = FORCED[k] + forced;
    return c(sire, dam);
}

1 early() {
    community.rescheduleScriptBlock(s1, NT + 1, NT + 1);
    for (k in 1:K) {
        pop = sim.addSubpop(k, N);
        haps = pop.haplosomes;
        muts = haps[0].addNewDrawnMutation(m1, 0:(L - 1));
        haps[0].removeMutations(muts);
        for (h in haps)
            h.addMutations(muts[runif(L) < 0.5]);
    }
}

reproduction() {
    k = 0;
    for (pop in sim.subpopulations) {
        inds = pop.individuals;
        pm = matings(pop, N, k);
        sire = pm[0:(N - 1)];
        dam = pm[N:(2 * N - 1)];
        for (i in 0:(N - 1)) {
            if (sire[i] == dam[i])
                pop.addSelfed(inds[sire[i]]);
            else
                pop.addCrossed(inds[sire[i]], inds[dam[i]]);
        }
        k = k + 1;
    }
    self.active = 0;
}

// Discrete generations: the parents die.
early() {
    inds = sim.subpopulations.individuals;
    inds[inds.age > 0].fitnessScaling = 0.0;
}

s1 1000000 late() {
    {
        k = 0;
        for (pop in sim.subpopulations) {
            f = sim.mutationFrequencies(pop);
            H = sum(2 * f * (1 - f)) / L;
            O = 0.0;
            for (ind in pop.individuals) {
                a = ind.haploidGenome1.mutations.position;
                b = ind.haploidGenome2.mutations.position;
                O = O + size(setSymmetricDifference(a, b));
            }
            O = O / (size(pop.individuals) * L);
            catn(SCHEME + "\t" + k + "\t" + H + "\t" + O + "\t" + FORCED[k]);
            k = k + 1;
        }
        sim.simulationFinished();
    }
}

# Mating schemes of FisherWright against a matched SLiM model
# (validate-mating.slim; docs/dev/roadmap.md, validation 4).
#
# Both simulators start from the same kind of polymorphic population (each
# of L = 1,000 sites on 20 chromosomes of 50 bp and 1 Morgan carried by each
# haplotype with probability 1/2), run NT = 30 generations of N = 40
# individuals without mutation under one mating scheme, and report Σ2pq/L,
# the observed heterozygosity H_obs and the number of offspring of
# relatives that could not be avoided. The schemes are implemented
# independently in Eidos, on SLiM's meiosis and pedigree. For each scheme
# and statistic the table gives the mean ± SE over R replicates of each
# simulator, the z-score of their difference, and, where it is known, the
# exact expectation (recursion of the heterozygosity within and between
# individuals) with the z-score of FisherWright against it.
#
# Usage: julia --project -t 8 validate-mating.jl SLIMDIR R SEED [SCHEMES]
# where SLIMDIR holds the SLiM output, one file <scheme>.tsv per scheme
# (columns scheme, replicate, Σ2pq/L, H_obs, forced), and SCHEMES is an
# optional space-separated list of scheme keys (all by default).

using FisherWright, Random, Statistics, Printf

const N, NT, L = 40, 30, 1_000
const CHR = fill(50, 20)

const SCHEMES = [
    ("rm", "RandomMating()", RandomMating()),
    ("rm5", "RandomMating(nmale=5)", RandomMating(nmale=5)),
    ("fsgamma", "FamilySize(dams=1.0, sires=:random, nmale=10)", FamilySize(dams=1.0, sires=:random, nmale=10)),
    ("hier", "Hierarchical(4, 3)", Hierarchical(4, 3)),
    ("mono", "Monoecious()", Monoecious()),
    ("self", "Monoecious(selfing=0.5)", Monoecious(selfing=0.5)),
    ("avoid_half", "AvoidRelatives(RandomMating(); level=:halfsib)", AvoidRelatives(RandomMating(); level=:halfsib)),
    ("avoid_cousin5", "AvoidRelatives(RandomMating(nmale=5); level=:cousin)",
        AvoidRelatives(RandomMating(nmale=5); level=:cousin)),
    ("avoid_mono", "AvoidRelatives(Monoecious(selfing=0); level=:fullsib)",
        AvoidRelatives(Monoecious(selfing=0.0); level=:fullsib)),
]

# Σ2pq/L (with replacement, over the 2N haplotypes) and H_obs.
function stats(haps)
    c = zeros(Int, L)
    for h in haps, p in h
        c[p] += 1
    end
    n = length(haps)
    H = sum(x -> 2 * (x / n) * (1 - x / n), c) / L
    O = mean(length(symdiff(haps[2i-1], haps[2i])) for i = 1:n÷2) / L
    return H, O
end

function run_fw(m, R, rng)
    out = zeros(R, 3)
    for r = 1:R
        start = [UInt32.(findall(rand(rng, Bool, L))) for _ = 1:2N]
        res = fisher_wright(N, NT, CHR, 1.0; M=50, init=start, mutate=false, mating=m, result=true, rng=rng)
        out[r, 1], out[r, 2] = stats(FisherWright._with_fixed(res))
        out[r, 3] = sum(res.related_matings)
    end
    return out
end

function read_slim(path)
    rows = [split(l, '\t') for l in eachline(path) if count(==('\t'), l) == 4]
    return [parse(Float64, r[k]) for r in rows, k = 3:5]
end

# Exact expectation of (Σ2pq/L, H_obs) after NT generations, from the
# probability a that two genes of different offspring come from one parent
# and the proportion σ of selfed offspring (both constant).
function expected(a, σ)
    hB = hW = 0.5
    for _ = 1:NT
        hB, hW = (1 - a) * hB + a / 2 * hW, (1 - σ) * hB + σ * hW / 2
    end
    return hW / 2N + (1 - 1 / N) * hB, hW
end

# Probability that two of n items split among m parents share one.
share(n, m, split) = split === :random ? 1 / m :
                     split === :equal ? (r = n % m; q = n ÷ m; (r * (q + 1) * q + (m - r) * q * (q - 1)) / (n * (n - 1))) :
                     (split + 1) / (m * split + 1)     # Gamma(split)
famA(n, Nm, Nf, ds, ss) = (Pf = share(n, Nf, ds); (Pf + Pf + (1 - Pf) * share(Nf, Nm, ss)) / 4)

function theory(key)
    key == "rm" || key == "rm5" || key == "fsgamma" || key == "hier" || key == "mono" || key == "self" || return nothing
    key == "mono" && return expected(1 / N, 1 / N)
    key == "self" && return expected(1 / N, 0.5)
    key == "rm5" && return expected(1 / 20 + 1 / 140, 0.0)
    key == "fsgamma" && return expected(famA(N, 10, 30, 1.0, :random), 0.0)
    key == "hier" && return expected(famA(N, 4, 12, :equal, :equal), 0.0)
    # Binomial sex, conditioned on both sexes: E[a] over the number of males.
    p = [binomial(big(N), k) for k = 1:N-1]
    a = sum(Float64(p[k]) * (1 / 4k + 1 / 4(N - k)) for k = 1:N-1) / Float64(sum(p))
    return expected(a, 0.0)
end

function main(slimdir, R, seed, only=nothing)
    println("FisherWright ", pkgversion(FisherWright), ", Julia ", VERSION, ", threads ", Threads.nthreads())
    println("N = $N, $NT generations, L = $L sites on 20 chromosomes of 1 Morgan, R = $R replicates per simulator, seed $seed")
    println()
    @printf("%-14s %-8s %20s %20s %7s %10s %7s\n", "scheme", "stat", "FisherWright", "SLiM", "z", "theory", "z(FW)")
    rng = Xoshiro(seed)
    for (key, label, m) in SCHEMES
        only === nothing || key in only || continue
        fw = run_fw(m, R, rng)
        sl = read_slim(joinpath(slimdir, key * ".tsv"))
        th = theory(key)
        println("# ", label, "  (SLiM replicates: ", size(sl, 1), ")")
        for (k, name) in enumerate(("Σ2pq/L", "H_obs", "forced"))
            a, b = fw[:, k], sl[:, k]
            ma, mb = mean(a), mean(b)
            sa, sb = std(a) / sqrt(length(a)), std(b) / sqrt(length(b))
            if sa == 0 && sb == 0
                @printf("%-14s %-8s %20s %20s\n", key, name, @sprintf("%.4g", ma), @sprintf("%.4g", mb))
                continue
            end
            z = (ma - mb) / sqrt(sa^2 + sb^2)
            t = th === nothing || k == 3 ? "" : @sprintf("%.5f", th[k])
            zt = th === nothing || k == 3 ? "" : @sprintf("%.2f", (ma - th[k]) / sa)
            @printf("%-14s %-8s %20s %20s %7.2f %10s %7s\n", key, name,
                @sprintf("%.5f ± %.5f", ma, sa), @sprintf("%.5f ± %.5f", mb, sb), z, t, zt)
        end
    end
end

main(ARGS[1], parse(Int, ARGS[2]), parse(Int, ARGS[3]), length(ARGS) > 3 ? split(ARGS[4]) : nothing)

#!/usr/bin/env bash
# Mating schemes of FisherWright against SLiM (validation 4).
#
# Usage: validate-mating.sh SLIM OUTDIR R SEED [JOBS]
#   SLIM    path to the slim executable (SLiM 5)
#   OUTDIR  directory for the SLiM output and the report
#   R       replicates per scheme and simulator (a multiple of 100)
#   SEED    base seed; SLiM process j of a scheme uses SEED * 1000 + j
#   JOBS    SLiM processes run in parallel (default 8)
# The environment variable SCHEMES restricts the run to some schemes, for
# example SCHEMES="rm avoid_cousin5".
# Run from the root of the FisherWright repository.
set -euo pipefail
slim=$1 out=$2 reps=$3 seed=$4 jobs=${5:-8}
here=$(dirname "$0")
mkdir -p "$out"
schemes=${SCHEMES:-"rm rm5 fsgamma hier mono self avoid_half avoid_cousin5 avoid_mono"}
nproc=$((reps / 100))
"$slim" -v > "$out/slim-version.txt"
for s in $schemes; do
    rm -f "$out/$s.tsv"
    seq 1 "$nproc" | xargs -P "$jobs" -I{} sh -c \
        "'$slim' -s \$(( $seed * 1000 + {} )) -d \"SCHEME='$s'\" -d N=40 -d NT=30 -d K=100 \
         '$here/validate-mating.slim' | grep -P '^$s\t' > '$out/$s.{}.part'"
    cat "$out/$s".*.part > "$out/$s.tsv"
    rm -f "$out/$s".*.part
done
{
    echo "commit $(git rev-parse --short HEAD), $(head -1 "$out/slim-version.txt"), $(uname -n), $(date -u +%Y-%m-%dT%H:%MZ)"
    julia --startup-file=no --project -t 8 "$here/validate-mating.jl" "$out" "$reps" "$seed" "$schemes"
} | tee "$out/report.txt"
