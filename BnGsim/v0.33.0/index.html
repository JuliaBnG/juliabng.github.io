BnGsim.jl

BnGsim.jl simulates breeding programs in the JuliaBnG ecosystem. Version 0.4 runs discrete-generation breeding programs and provides the building blocks:

  • Founders: Wright–Fisher burn-in through FisherWright.jl (historical_population, continue_population), founder sampling (founder_haplotypes, sample_founder_population), and readers and writers for packed haplotype files.
  • Keyed streams: SimKey addresses every random stream by its coordinate in the simulation, so results do not depend on thread count or call order (keyed_rng).
  • Meiosis: MeiosisMap and make_progeny! (keyed, word-wise, with per-chromosome genetic lengths and optional crossover records); the older gamete!/gene_drop! with an explicit rng; random_mate, rnd_ped.
  • Breeding loop: founder_population, Scheme and simulate!: phenotypes, evaluation through Breeding.jl (true values, phenotype, PBLUP, GBLUP), selection by truncation, optimum contributions (TM1997, rocs) or at random, keyed mating and meiosis, with per-generation summaries; discrete or overlapping generations, several traits with selection on an index of multi-trait EBVs, sex- and age-limited records, survival and culling, single-step GBLUP, optional REML re-estimation of the variance components, and checkpoints.
  • Traits: QTL sampling (sample_loci, eqtl, which keeps the shape of the effect distribution and sets the mean through the intercept), trait_summary, true breeding values (tbv!), and phenotypes with correlated residuals, sex-limited expression and threshold traits (phenotype!).
  • Diagnostics and provenance: founder_summary, ld_decay, vanraden_g, provenance.

Every stochastic function takes an explicit rng. See the Roadmap for the planned scenario, evaluation and selection layers.

A breeding program

using BnGStructs, BnGsim, Random

sp   = GenericSpecies("toy", [20_000_000, 10_000_000])
rng  = Xoshiro(1)
vm   = VariantMap(sort(unique(rand(rng, 1:30_000_000, 2000))), sp)
hap  = Haplotype(BitMatrix(rand(rng, Bool, length(vm), 400)))      # 200 founders
t    = Trait("y"; h² = 0.3, σₐ = 1.0)
qtl  = eqtl(hap, 1:5:length(vm), t; rng = rng)
pop  = founder_population(hap, qtl, t, SimKey(2026))
sc   = Scheme(; noff = 200, nsire = 10, ndam = 50, evaluation = :pblup)
simulate!(pop, sc, MeiosisMap(sp, vm), 10)    # one row per generation

Installation

BnGsim requires Julia 1.10 (LTS) or later.

using Pkg
Pkg.add("BnGsim")

Quick start

using BnGStructs, BnGsim, Random

rng = Xoshiro(2026)
fp  = sample_founder_population(Cattle(); ne = 100, n_id = 20, n_marker = 500, n_qtl = 50,
                                h2 = 0.3, burnin_generations = 200, rng = rng)
fp.tbv           # true breeding values of the founders
fp.markers.loci  # marker chip loci in fp.map
