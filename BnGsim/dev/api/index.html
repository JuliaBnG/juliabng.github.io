BnGsim.FounderPopulation — Type
struct FounderPopulation

Holds the complete state of a sampled founder population for breeding simulations.

Fields

  • species::Species: Biological species definition (e.g. Cattle, Pig).
  • haplotype::Haplotype: Base genome haplotypes (nlc × 2nid).
  • map::VariantMap: Variant genomic map (VariantMap from BnGStructs).
  • markers::LocusSet: Marker chip panel (LocusSet from BnGStructs).
  • qtl::TraitQTL: Single-trait QTL architecture.
  • h2::Float64: Target heritability.
  • tbv::Vector{Float64}: True Breeding Values for the n founder individuals.
  • phenotypes::Vector{Float64}: Simulated phenotypes (y = TBV + e).
  • pedigree::DataFrame: Pedigree with columns :id, :sire, :dam (sire/dam = 0 for founders).

Note: fp.marker_indices is also supported as a property alias returning fp.markers.loci.

BnGsim.HistoricalSpec — Type
struct HistoricalSpec

A historical (pre-founder) population run with FisherWright.fisher_wright.

Fields

  • name::String: arm label, e.g. "F2".
  • ne::Int: diploid population size, constant over the run.
  • nt::Int: number of discrete, non-overlapping generations.
  • mr::Float64: mutations per 1e8 bp per meiosis (μ = mr × 1e-8).
  • chromosome::Vector{UInt32}: autosome lengths in bp.
  • M::Float64: bp per Morgan (1e8 is 1 cM/Mb).

Model, as implemented by FisherWright with its neutral defaults: diploid, dioecious Wright-Fisher population with random union of gametes; infinite-sites mutation; Poisson crossovers without interference; independent assortment of chromosomes; the genome starts monomorphic, so nt determines how close the run is to mutation-drift equilibrium (about 10ne generations for the frequency spectrum, much less for LD at short distances).

BnGsim.continue_population — Method
continue_population(res::FisherWrightResult, ns, mr; M = 1e8, mut_base = 1e8,
                    rng = Random.default_rng()) -> FisherWrightResult

Continue a FisherWright population for length(ns) further generations with census size ns[g] in generation g, e.g. a decline from the historical size to a breed-like size before founders are sampled (arm F5). The model is the same as in fisher_wright (dioecious WF, Poisson crossovers at 1/M per bp, infinite-sites mutation at mr / mut_base per bp per meiosis), except that the population size may change every generation.

Runs on one thread with the explicit rng, so it is reproducible regardless of the thread count. Mutations that fix during the continuation stay in the haplotypes; muts2bitarray drops them as monomorphic.

Uses FisherWright internals (random_mate!, cobp!, recombine, merge_sorted); test/runtests.jl guards that contract.

BnGsim.founder_haplotypes — Method
founder_haplotypes(fxy::AbstractString, fmp::AbstractString, nid, cbp;
                   rng = Random.default_rng()) -> (xy::BitMatrix, lmp::DataFrame)

Sample nid founders from a historical population stored by xyBnG (the WCGALP base, arm F1): fxy is an xy file holding a locus-major BitMatrix (8-byte header xy-, then nrow, ncol as Int64, then the bits) and fmp a serialized map DataFrame with genome-wide pos.

FisherWright v0.1.x wrote some loci out of order (a few blocks near the end of the genome). Here rows are sorted by pos and chr is recomputed from the cumulative chromosome ends cbp, so the output follows the same conventions as the FisherWrightResult method: loci segregating among the sampled founders, sorted, frq the sample frequency of allele 1.

BnGsim.founder_haplotypes — Method
founder_haplotypes(res::FisherWrightResult, nid; rng = Random.default_rng())
    -> (xy::BitMatrix, lmp::DataFrame)

Sample nid individuals without replacement from the final generation of res and return their phased haplotypes at the loci segregating among them. Columns 2i-1 and 2i are the two haplotypes of founder i. Alleles are coded ancestral = 0, derived = 1 (no flipping), and lmp.frq is the derived-allele frequency in the sample. lmp.pos is the genome-wide coordinate; lmp.chr the chromosome.

BnGsim.founder_summary — Method
founder_summary(xy, lmp; nchip = 20_000, chip_maf = 0.2, nqtl = 10_000, qtl_maf = 0.0,
                presample = 3, rare = 0.05, ld = (;), rng = Random.default_rng())
    -> (scalars::NamedTuple, sfs::DataFrame, ld::DataFrame, chip, qtl)

Founder-level outcomes of plan §4.3 for one replicate of one arm. xy holds the founders' phased haplotypes at the loci segregating among them, lmp their map with sample frequencies (founder_haplotypes).

Chip and QTL loci are drawn as in the WCGALP pipeline (xyBnG founder_pop): presample × nchip chip candidates with sample MAF > chip_maf are set aside first, and the QTL are drawn from the loci with MAF > qtl_maf that are left, so the QTL are depleted of common loci when the founders have few of them. The chip is nchip of the candidates and nqtl QTL are kept. (The pipeline makes its final cut after the founder expansion, among the candidates that still meet the MAF condition; here it is made among the founders.) presample = 1 removes only the chip, which is what this function did before 2026-11-11 and does not describe the pipeline. Scalars:

  • nid, nseg: founders, segregating sites;
  • sum2pq: Σ2pq over all segregating sites (expected heterozygosity × sites);
  • n_maf02: sites with MAF ≥ 0.2, the pool for the chip;
  • chip_r2_adj: mean r² between adjacent chip markers on a chromosome, and chip_gap, their mean spacing (bp);
  • qtl_maf_mean, qtl_rare: mean QTL MAF and the fraction with MAF < rare;
  • qtl_rare_va: share of Σ2pq over QTL carried by QTL with MAF < rare, i.e. the expected share of V_A from rare QTL under i.i.d. effects;
  • qtl_maf02: fraction of QTL with MAF ≥ 0.2;
  • g_diag, g_offsd: mean diagonal and SD of off-diagonals of the founder-centred VanRaden G at the chip;
  • me: 1 / var(G off-diagonal), the effective number of independent chromosome segments implied by realized relationships (Goddard 2009).

sfs is the folded MAF spectrum in 0.05 bins; ld is ld_decay with keyword arguments ld.

BnGsim.ld_decay — Method
ld_decay(xy, lmp; minmaf = 0.05, edges = [5e3, 1e4, 2e4, 5e4, 1e5, 2e5, 5e5, 1e6, 2e6, 5e6],
         npairs = 20_000, M = 1e8, rng = Random.default_rng()) -> DataFrame

Haplotype r² between loci with sample MAF ≥ minmaf, in distance bins [edges[k], edges[k+1]) bp. For each bin, npairs pairs on the same chromosome are drawn by picking a random anchor locus and a random partner in the bin downstream of it.

Columns: lo, hi, d (mean distance of the sampled pairs), n, r2 (mean), r2adj = r2 - 1/nh (sample-size correction for nh phased haplotypes), and the Sved (1971) LD-based effective size ne = (1/r2adj - 1) / (4c), c = d/M Morgan, which refers to about t = 1/(2c) generations ago (Hayes et al. 2003). ne is NaN when r2adj ≤ 0.

BnGsim.phenotype! — Method
phenotype!(
    ped::DataFrame,
    trts::Union{AbstractTrait, AbstractVector{<:AbstractTrait}};
    R_e::Union{Nothing, AbstractMatrix{<:Real}} = nothing,
    rng::AbstractRNG = Random.default_rng(),
) -> DataFrame

Generate phenotypes in ped (columns "ft_" * t.name) from true breeding values ("tbv_" * t.name) for one or more BnGStructs.AbstractTrait objects (aTrait or tTrait).

  • Environmental standard deviation for trait t is $\sigma_e = \sigma_a \sqrt{(1 - h^2) / h^2}$.
  • If R_e (a residual correlation matrix across trts) is given, environmental deviates are drawn jointly with correlation R_e.
  • Sex-limited traits (t.sex ∈ (0, 1)) set records for the non-expressing sex in ped.sex to missing.
  • Threshold traits (tTrait) discretize the latent liability $L = \text{TBV} + e$ against t.threshold into categories 0, 1, ..., length(t.threshold).

BnGsim.provenance — Function
provenance(io::IO = stdout; seed = nothing, extra = Dict{String,Any}())

Write a run header recording what is needed to reproduce a simulation: the date, host, CPU, Julia version, thread count, BLAS threads, the seed, and for each JuliaBnG package its version (Breeding only when loaded), git commit and whether its working tree was dirty. Lines are prefixed with # so the header can sit on top of a plain-text log or table.

Results from FisherWright.fisher_wright are reproducible for a given seed only at a fixed thread count, which is why the thread count is recorded.

BnGsim.read_packed_haplotypes — Method
read_packed_haplotypes(path, cbp; rng = Random.default_rng())
    -> (xy::BitMatrix, lmp::DataFrame)

Read phased haplotypes written by an external simulator (e.g. the msprime driver of the founder-design paper) in the BNGH1 format: 8-byte magic "BNGH1\0\0\0", Int64 nloci and nhap, UInt32 genome-wide positions, then each locus as cld(nhap, 8) bytes with haplotype h in bit (h-1) % 8 of byte (h-1) ÷ 8 (numpy packbits(bitorder = "little")). 1 is the derived allele; haplotypes 2i-1, 2i form individual i.

Returns the same layout as the FisherWrightResult method: loci segregating in the sample, sorted by position, chr from the cumulative chromosome ends cbp, frq the sample frequency of allele 1, and random ref/alt bases.
