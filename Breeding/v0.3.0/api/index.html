API reference

Package

Breeding.Breeding — Module
Breeding

Quantitative-genetics tools for genetic evaluation, genomic prediction, variance component estimation, and optimum contribution selection from pedigree and marker data.

Features

  • Mixed-model equations (MME): Henderson's MME with any number of random terms, each with correlated components ($G_0 \otimes K$): multiple traits with missing records, maternal and social/associative effects, random regressions on Legendre polynomials or linear splines; PEV and reliabilities.
  • Solvers and iteration on data: sparse Cholesky, preconditioned conjugate gradients (pcg), Gauss–Seidel and SOR (gauss_seidel with ω), Jacobi (jacobi), and matrix-free iteration on data (AnimalModelIOD).
  • Variance components: REML (reml, average-information or EM updates), Gibbs samplers (gibbs, gibbs_mt), Henderson's method 3 (henderson3), canonical sire contrasts (sire_contrasts, fit_mean_squares) and covariance functions (covariance_function).
  • Genomic prediction: genotype centring (center_genotypes), GBLUP in selection-index form (gblup_index), SNP effects from GBLUP (snp_from_gblup), base allele frequencies (base_allele_frequencies), pseudo-SNPs from phased haplotypes (pseudo_snps), $Z'Z$ of SNP-BLUP from dosages or haplotypes, accumulated over record batches (zpz!, zpz_hap!), and Bayes A, B, C and Cπ (bayes_snp).
  • Threshold models: probit threshold models solved by Fisher scoring (threshold_model), category probabilities (category_probabilities), and joint analysis of a quantitative and a binary trait (joint_binary_quantitative).
  • Partitions and reduced animal model: Mendelian-sampling precisions (mendelian_precision), PA/YD/PC and DYD partitions of EBV (ebv_partition, ebv_partition_mt), and the reduced animal model (ram_design, ram_backsolve).
  • Optimum contribution selection (OCS & ROCS): Meuwissen's (1997) target-coancestry OCS (TM1997, OC_fixsex2) and Fogg et al.'s (2026) robust optimal contribution selection (rocs, robust_ocs, ROCSResult).

Mixed model equations (MME)

Breeding.RandomEffect — Type
RandomEffect(Z, Kinv, σ²; name = "")
RandomEffect(Zs::Vector, Kinv, G0; name = "")

A random term of a linear mixed model with $m$ correlated components, each with $q$ levels:

\[\mathbf{u} = [\mathbf{u}_1' \cdots \mathbf{u}_m']', \quad \operatorname{var}(\mathbf{u}) = \mathbf{G}_0 \otimes \mathbf{K},\]

contributing $\sum_c \mathbf{Z}_c \mathbf{u}_c$ to the records. Zs[c] (nobs × q) relates records to component c, Kinv is $\mathbf{K}^{-1}$ (q × q; e.g. $A^{-1}$, $G^{-1}$, $H^{-1}$, $D^{-1}$ or I) and G0 is the m × m covariance among components.

This covers, among others:

  • one component: animal, sire, permanent environment, litter, SNP, …;
  • direct + maternal (or direct + social) genetic effects, where Zs are the calf and dam (or group-mate) incidence matrices;
  • multiple traits, where Zs[t] maps trait t records (see mt_blocks);
  • random regressions, where Zs[c] = Diagonal(Φ[:, c]) * Z.

Solutions are ordered component-major (all levels of component 1, then component 2, …), matching $\mathbf{G}_0^{-1} \otimes \mathbf{K}^{-1}$.

Breeding.MME — Type
MME

Mixed-model equations $\mathbf{C}\hat{\theta} = \mathbf{r}$ built by mme. Fields: lhs, rhs, the equation ranges blocks (fixed effects first, then one range per random effect), effects, and scale – the residual variance the equations were multiplied by (1 when a full $R^{-1}$ was supplied), so that $\operatorname{PEV} = C^{-1} \cdot$ scale.

source
Breeding.mme — Function
mme(y, X, effects; σ²e = nothing, Rinv = nothing) -> MME

Set up Henderson's mixed-model equations for

\[\mathbf{y} = \mathbf{Xb} + \sum_k \mathbf{Z}_k \mathbf{u}_k + \mathbf{e}, \quad \operatorname{var}(\mathbf{u}_k) = \mathbf{G}_{0k} \otimes \mathbf{K}_k, \quad \operatorname{var}(\mathbf{e}) = \mathbf{R}.\]

  • With σ²e ($\mathbf{R} = \mathbf{I}\sigma^2_e$) the equations are scaled by $\sigma^2_e$, as printed in Mrode: $\mathbf{W'W} + \sigma^2_e \oplus_k (\mathbf{G}_{0k}^{-1} \otimes \mathbf{K}_k^{-1})$, giving the familiar variance ratios $\alpha$.
  • With Rinv (a matrix, or a vector of diagonal weights) the unscaled $\mathbf{W'R^{-1}W} + \oplus_k (\mathbf{G}_{0k}^{-1} \otimes \mathbf{K}_k^{-1})$ is built. Use it for heterogeneous residuals, reduced animal models, or multiple traits (mt_rinv).

X may have zero columns; effects is a vector of RandomEffects (possibly empty). All products are sparse.

Breeding.solve_mme — Function
solve_mme(m::MME; zero = Int[], method = :direct, x0 = nothing, kw...) -> Vector{Float64}
solve_mme(lhs, rhs; zero = Int[], method = :direct, x0 = nothing, kw...)

Solve the mixed-model equations. Equations listed in zero are removed and their solutions set to zero; this imposes the usual $\hat{b}_k = 0$ constraints when $\mathbf{X}$ is not of full column rank (e.g. one level of each extra fixed factor, or one unknown parent group).

method:

  • :direct – sparse Cholesky (CHOLMOD) of the positive definite system; falls back to sparse LU if Cholesky fails;
  • :pinv – dense Moore–Penrose solution (small, rank-deficient systems only);
  • :pcg, :gauss_seidel, :sor, :jacobi – iterative solvers of Chapter 19 (pcg, gauss_seidel, jacobi); keywords are passed on.

x0 (length length(rhs), e.g. the previous round's solutions) is the starting value of the iterative solvers; entries of zero are dropped from it. The direct methods ignore it.

Breeding.pev — Function
pev(m::MME, k::Integer; zero = Int[]) -> Matrix{Float64}

Prediction-error variances $\operatorname{var}(u - \hat{u})$ of the kth random effect, as a q × m matrix (levels × components). They are the diagonal of the corresponding block of $\mathbf{C}^{-1}$ times m.scale. The coefficient matrix is factorized once and only the required columns of the inverse are solved for.

source
Breeding.pev_candidates — Function
pev_candidates(m::MME, k, candidates; component = 1, zero = Int[]) -> Matrix{Float64}

Prediction error (co)variance matrix $\mathrm{Var}(\mathbf{u}_c - \hat{\mathbf{u}}_c)$ of the levels candidates of random effect k, component component: the block of the inverse coefficient matrix for those equations, times the residual scale. Its diagonal equals the matching elements of pev. Only length(candidates) right-hand sides are solved, so the full inverse is never formed.

The result is the matrix Ω that rocs expects. Equations in zero are constrained to zero as in solve_mme; a candidate may not be one of them.

source
pev_candidates(K, ref, candidates, X, λ; σ²a = 1.0, w = nothing) -> Matrix{Float64}

The same matrix from the selection-index (V) form, without inverting K. With records on the animals ref, relationship matrix K over all animals, fixed-effect design X (one row per record, full column rank) and $\lambda = \sigma^2_e / \sigma^2_a$,

\[\boldsymbol\Gamma = \sigma^2_a \left(\mathbf{K}_{cc} - \mathbf{K}_{cr}\mathbf{P}\mathbf{K}_{rc}\right), \qquad \mathbf{P} = \mathbf{V}^{-1} - \mathbf{V}^{-1}\mathbf{X}(\mathbf{X}'\mathbf{V}^{-1}\mathbf{X})^{-1}\mathbf{X}'\mathbf{V}^{-1},\]

where $\mathbf{V} = \mathbf{K}_{rr} + \lambda\mathbf{I}$, or $\mathbf{K}_{rr} + \lambda\,\mathrm{diag}(1/w)$ with record weights w as in gblup_index. K may be A, G, H or an IBD matrix; it need not be invertible. Candidates may be among ref.

This equals the mixed-model form when K is invertible and the fixed effects are the same.

Breeding.selected_inverse — Function
selected_inverse(m::MME; zero = Int[]) -> SparseMatrixCSC{Float64,Int}
selected_inverse(lhs::SparseMatrixCSC; zero = Int[])

Selected elements of the inverse of the MME coefficient matrix: every element of $\mathbf{C}^{-1}$ on the sparsity pattern of the Cholesky factor of $\mathbf{C}$, which contains the pattern of $\mathbf{C}$ itself (Takahashi equations, through SelectedInversion.jl). Elements outside that pattern are not computed and read as zero; they are not zeros of the inverse. Multiply by m.scale for prediction error (co)variances.

This is what large models can afford in place of lhs_inverse: memory and time are those of the sparse factorisation. It gives the diagonal (hence pev and reliability), the covariances between an animal and its parents and mates, and the traces that REML needs. For a dense block among arbitrary candidates use pev_candidates.

The coefficient matrix must be positive definite after the equations in zero are removed.

source
Breeding.reliability — Function
reliability(m::MME, k::Integer; zero = Int[], Kdiag = nothing) -> Matrix{Float64}

Reliability $r^2 = 1 - \operatorname{PEV}/\sigma^2_u$ of the levels of random effect k, per component ($\sigma^2_u$ is the diagonal of G0 times the diagonal of $\mathbf{K}$). Without Kdiag, $\operatorname{diag}(\mathbf{K})$ is taken from the selected inverse of a sparse $\mathbf{K}^{-1}$ (or a dense inverse of a dense one); for $\mathbf{K} = A$, Kdiag = nrm_diag(ped) (i.e. $1 + F_i$) is cheaper still. For non-inbred animals this is Henderson's $1 - d_i\alpha$.

Solvers and iteration-on-data (IOD)

Breeding.pcg — Function
pcg(A, b; M = diag(A), x0 = zeros(length(b)), tol = 1e-12,
    maxiter = 10 * length(b), criterion = :residual, uplo = :L,
    history = false) -> (x, iterations, conv[, hist])

Preconditioned conjugate gradient for a symmetric positive (semi-) definite system (Lidauer et al., 1999; Mrode Section 19.6). A is a matrix or a function A(v, d) that overwrites v with $\mathbf{A}d$ – e.g. an iteration-on-data operator such as AnimalModelIOD – in which case M (the diagonal preconditioner) must be given. Convergence is $\|b - Ax\| / \|b\|$ (criterion = :residual) or Mrode's change criterion (criterion = :change).

A dense BLAS matrix is multiplied as Symmetric(A, uplo) (BLAS symv), which reads only one triangle and halves the memory traffic of a large SNP-BLUP system; only that triangle of A needs to be filled. Sparse matrices and operators are used as given.

Breeding.gauss_seidel — Function
gauss_seidel(A, b; x0 = zeros, ω = 1.0, tol = 1e-9, maxiter = 10_000,
             history = false) -> (x, iterations, conv[, hist])

Gauss–Seidel (ω = 1) or successive over-relaxation iteration on a symmetric sparse system. Because $\mathbf{A}$ is symmetric, row i is read from column i of the CSC storage, so one sweep costs one pass over the non-zeros. Arguments as in jacobi.

source
gauss_seidel(m::AnimalModelIOD; x0 = zeros, fix = Dict{Int,Float64}(),
             tol = 1e-9, maxiter = 10_000, history = false)

Gauss–Seidel iteration on the data (Mrode Examples 19.3 and 19.4). Fixed-effect levels are solved from records adjusted for the current solutions of all other effects; each animal (and group) is solved from its records, its parents and its progeny adjusted for their mates. Equations in fix (equation index => value) are held at the given values, e.g. to constrain group solutions.

source
Breeding.jacobi — Function
jacobi(A, b; x0 = zeros, ω = 1.0, second_order = false, tol = 1e-9,
       maxiter = 10_000, history = false) -> (x, iterations, conv[, hist])

Jacobi (total-step) iteration on $\mathbf{Ax} = \mathbf{b}$, with relaxation

\[x^{(r+1)} = \omega \, M^{-1}(b - Ax^{(r)}) + x^{(r)},\]

where $M = \operatorname{diag}(A)$. ω is a scalar or a vector of per-equation factors (Mrode uses 1 for fixed effects and 0.8 for animal equations). With second_order = true the second-order Jacobi $x^{(r+1)} = M^{-1}(b - Ax^{(r)}) + x^{(r)} + ω(x^{(r)} - x^{(r-1)})$ is used. Iteration stops when Mrode's convergence criterion (sum of squared changes divided by sum of squared current solutions) is below tol. With history = true the solutions of every round (columns, starting with x0) are returned as a fourth value.

source
Breeding.AnimalModelIOD — Type
AnimalModelIOD(y, fixed, animal, sire, dam, α; F = nothing)

Iteration-on-data (Schaeffer and Kennedy, 1986) representation of the univariate animal model

\[y = \sum_f X_f b_f + Z a + e, \quad \operatorname{var}(a) = A\sigma^2_a, \quad \alpha = \sigma^2_e / \sigma^2_a,\]

that never forms the coefficient matrix. Only the data, the pedigree and progeny lists are stored.

  • fixed: vector of factors, each a vector of level indices 1:nₖ (one per record);
  • animal: animal index of each record;
  • sire, dam: parents of animals 1:N; 0 = unknown, N + g = unknown parent group g (phantom parents, QP-transformed $A^{-1}$; Westell et al., 1988);
  • F: optional inbreeding coefficients of animals 1:N, used in the Mendelian-sampling precisions exactly as in RelationshipMatrices.ainv.

Equation order is: levels of each fixed factor, animals 1:N, groups. Use gauss_seidel on it for Gauss–Seidel iteration on data, or pcg with the operator, diag(m) and rhs(m).

Covariables of a linear spline with the given (sorted) knots for random-regression models (Misztal, 2006): a time t between knots $T_i$ and $T_{i+1}$ gets $(T_{i+1} - t)/(T_{i+1} - T_i)$ on knot i and $(t - T_i)/(T_{i+1} - T_i)$ on knot i+1; outside the knots, Mrode's rules $t/T_1$ and $T_n/t$ are applied to the end knot. Breeding.mtpblup — Function
mtpblup(ped, trts, giv, G; kw...)

Perform multi-trait PBLUP to estimate breeding values for traits trts in pedigree ped using the inverse relationship matrix giv and genetic (co)variance matrix G. Estimated breeding values (EBV) are written into ped.

This is a simplified multi-trait animal model:

\[\mathbf{y} = \mathbf{Xb} + \mathbf{Zu} + \mathbf{e}, \quad \operatorname{var}(\mathbf{u}) = \mathbf{G} \otimes \mathbf{A}, \quad \operatorname{var}(\mathbf{e}) = \mathbf{R} = \bigoplus_{t=1}^{T} \sigma^2_{e,t} \mathbf{I}\]

with trait-specific residual variances $\sigma^2_{e,t} = G_{tt}(1 - h^2_t)/h^2_t$ and zero residual covariances. Only general trait means are fitted as fixed effects; maternal and permanent environmental effects are omitted.

Arguments

  • ped : DataFrame with phenotype columns "ft_" * trait.name for the traits in trts, one row per animal in the order of giv. EBV are written to "ebv_" * trait.name.
  • trts : Vector{Trait}, ordered identically to rows and columns of G. Each trait must define name and h².
  • giv : SparseMatrixCSC, inverse additive relationship matrix $\mathbf{A}^{-1}$ of ped.
  • G : Matrix, genetic (co)variance matrix among traits.
  • kw... : passed to solve_mme. Defaults to method = :pcg with pcg's defaults (Jacobi preconditioner, relative residual tol = 1e-12), warm-started from the existing "ebv_*" column of each trait (missing treated as 0.0); a trait without one starts from zeros.

Returns

nothing; EBV are written to columns "ebv_" * trait.name of ped (updating existing vectors in-place or creating new columns).

Notes

  • Only complete cases across all traits (records non-missing for every trait in trts) are included in the evaluation.
  • The coefficient matrix is set up via mme as $\mathbf{W'R^{-1}W} + \mathbf{G}^{-1} \otimes \mathbf{A}^{-1}$.

Variance component estimation

Breeding.reml — Function
reml(y, X, effects; σ²e | residual, method = :ai, param = :natural,
     zero = Int[], fix = Int[], equal = Vector{Int}[], tol = 1e-8, ltol = nothing,
     ntol = nothing, maxiter = 200, maxhalve = 10, maxstep = 5.0,
     backend = :auto) -> REMLResult

Restricted maximum likelihood (Patterson and Thompson, 1971) for the mixed model

\[y = Xb + \sum_k Z_k u_k + e, \quad \operatorname{var}(u_k) = G_{0k} \otimes K_k, \quad \operatorname{var}(e) = R,\]

where each RandomEffect in effects supplies $Z_k$, $K_k^{-1}$ and the starting $G_{0k}$ (so correlated direct–maternal effects or random-regression covariance matrices are estimated too). The residual structure is given either as σ²e (starting value of a homogeneous variance) or as residual, a Homogeneous, HetClasses or MultiTrait with starting values. zero lists constrained fixed effects (as in solve_mme).

Multi-trait models use observations in long format (one element of y per record of one trait): trait-specific fixed effects are columns of X, and a random effect covering several traits has one component per trait (and regression coefficient), its Z having nonzeros only for the records of that trait; $G_{0k}$ is then the covariance matrix among all of them. The residual structure is a MultiTrait.

method:

  • :ai – average information (Gilmour et al., 1995): first derivatives from MME solutions and traces of $C^{-1}$, and $AI_{ij} = \tfrac12 f_i'Pf_j$ from working variates $f_i = (\partial V/\partial\theta_i)Py$ ($(\partial R/\partial\theta_i) R^{-1}\hat e$ for residual parameters, $Z_k(\partial G_{0k} G_{0k}^{-1} \otimes I)\hat u_k$ for $G_{0k}$). The AI matrix is made safely positive definite by adding $\tau I$, $\tau = \max(0, \delta - \lambda_{min})$, $\delta = 3 \times 10^{-6}\lambda_{max}$ (WOMBAT's default modification). A step must not decrease the log-likelihood; otherwise it is halved up to maxhalve times, then replaced by an EM step.
  • :em – expectation maximization: for homogeneous residuals $(n - p)\sigma^2_e = e'y$; otherwise, for every residual class, $R_0 = N^{-1}\sum_g E(e_g e_g' \mid y)$ over its $N$ groups, with $E(e_ge_g') = B_g(\hat e_g\hat e_g' + W_gC^{-1}W_g')B_g'$ plus the conditional covariance of the residuals of traits not recorded in the group ($B_g$ predicts them from those recorded; for single-trait classes $n_c\sigma^2_c = e_c'e_c + \operatorname{tr}(C^{-1}W_c'W_c)$); and $G_{0k} = (\hat U_k'K_k^{-1}\hat U_k + T_k)/q_k$ with $T_k[i,j] = \operatorname{tr}(C^{k_ik_j}K_k^{-1})$.

Constraints (with param = :natural): fix lists parameters (indices into the parameter vector, ordered as AIinv) kept at their starting values, e.g. zero covariances between blocks of a covariance matrix; equal lists sets of parameters estimated as one value (started at their mean), e.g. the same variance in several classes. Steps are taken on the free parameters $eta$ with $heta = heta_0 + Keta$, gradient $K'g$ and average information $K'AK$; AIinv is then $K(K'AK)^{-1}K'$. A fall-back EM step is projected onto the constraints and taken only if it does not decrease the log-likelihood.

param (AI only): :natural takes AI steps on the covariances themselves (steps leaving the parameter space are halved); :cholesky on log residual variances (single-trait structures) and the Cholesky factors of all other covariance matrices with log-transformed diagonals, which keeps every iterate positive definite. The average information is computed on the covariance scale and transformed with the Jacobian (as in WOMBAT). With :cholesky, no element of a step may exceed maxstep (the step is scaled down), and every Cholesky pivot is kept at least $10^{-4}$ times the largest pivot of its matrix, so that estimates on the boundary of the parameter space remain numerically positive definite.

Iteration stops when the largest change in a covariance parameter is below tol times the largest parameter (at least 1); or, if ltol is given, when an AI step increases the log-likelihood by less than ltol (WOMBAT uses $5 \times 10^{-4}$) and, if ntol is given, the increase expected from the next AI step, $\tfrac12 g'H^{-1}g$ (half the Newton decrement, with $g$ the gradient and $H$ the modified AI matrix on the scale of param), is below ntol; or after maxiter iterates. On flat likelihood surfaces a single small increase does not mean that the maximum is near; ntol guards against stopping early. Near the boundary of the parameter space the likelihood can be very flat in some directions, and the parameter criterion alone may need many iterates.

The log-likelihood is $-\tfrac12[y'Py + \log|V| + \log|X'V^{-1}X|]$ computed through $\log|C| + \log|R| + \sum_k \log|G_k|$.

backend: both back-ends assemble $C$ on one sparsity pattern kept over all iterates. :dense then inverts $C$ densely (small models); :sparse reuses the symbolic CHOLMOD factorisation, takes the traces from the selected inverse of $C$ on its own pattern (Takahashi equations, via SelectedInversion.jl) and the AI matrix from solves with the factor; :auto (default) uses :sparse above 2000 equations. Dense relationship matrices (e.g. $G^{-1}$) make the corresponding blocks of $C$ and its factor dense.

Breeding.REMLResult — Type
REMLResult

Output of reml, all at the returned estimates:

  • σ²e: the residual variance (homogeneous residuals; NaN otherwise); R0: the residual covariance matrix of every class ($1 \times 1$ for single-trait structures); residual: the residual parameters (the lower triangle of each R0 by columns, i.e. the variance of every class for HetClasses);
  • G0: the covariance matrices of the random effects;
  • logL: the restricted log-likelihood (Mrode's form, without constants, as in WOMBAT);
  • AIinv: the inverse of the average-information matrix on the covariance scale (approximate sampling covariances); parameter order: residual, then the lower triangle of each G0, by columns;
  • history: parameters per iterate (one column each, starting with the initial values), logLs: their log-likelihoods;
  • iterations, and the mixed-model solutions;
  • steps: for every iterate, the fraction of the AI step taken (1 for a full step, $2^{-h}$ after $h$ halvings), or 0 for an EM step.

Breeding.MultiTrait — Type

Breeding.gibbs — Function
gibbs(y, X, effects; σ²e, νe = -2, Se = 0.0, νu = nothing, Vu = nothing,
      zero = Int[], niter = 10_000, burnin = 1_000, thin = 1,
      estimate_variances = true, rng = Random.default_rng()) -> GibbsResult

Gibbs sampler for variance components and breeding values of the univariate mixed model of mme (Wang et al., 1993; Sorensen and Gianola, 2002; Mrode Section 18.2): flat priors on fixed effects, $u_k | G_{0k} \sim N(0, G_{0k} \otimes K_k)$, and

  • $\sigma^2_e | \cdot \sim (e'e + \nu_e S_e)/\chi^2_{n + \nu_e}$;
  • $G_{0k} | \cdot \sim IW(\nu_{uk} + q_k,\ U_k'K_k^{-1}U_k + V_{uk})$, a scaled inverse χ² for single-component effects.

The defaults (νe = -2, Se = 0, νu = -(m+1), Vu = 0) are the uniform priors of Mrode's examples. Locations are sampled with gibbs_sweep! on the MME, which are rebuilt from the precomputed $W'W$ and $W'y$ at every round. Samples after burnin are kept every thin rounds. With estimate_variances = false the variances stay at their starting values, and the posterior means of the location parameters converge to the BLUP solutions.

Breeding.gibbs_mt — Function
gibbs_mt(Y, X, Z, Kinv; R0, G0, νe = -(t+1), Ve = 0, νu = -(t+1), Vu = 0,

         rng = Random.default_rng()) -> GibbsResult

Block Gibbs sampler for a multi-trait animal model with equal design matrices (Jensen et al., 1994; Mrode Section 18.3): $Y = XB + ZU + E$, rows of $E$ $\sim N(0, R)$, $\operatorname{vec}(U) \sim N(0, G \otimes K)$. Y is n × t and may contain missing or NaN; missing records are sampled from their conditional distribution given the observed traits of the same record (data augmentation) before each round.

The defaults are uniform priors; estimate_variances = false keeps R0 and G0 fixed. In the result, x holds vec([B; U]) (levels in rows, traits in columns).

Breeding.gibbs_sweep! — Function

One round of single-site Gibbs sampling of the location parameters of mixed-model equations $Cx = r$ (Mrode Eqns 18.11–18.12): in equation order, $x_j$ is drawn from

\[N\big((r_j - \textstyle\sum_{k \ne j} c_{jk}x_k)/c_{jj},\ \text{scale}/c_{jj}\big),\]

using the newest values of all other parameters. scale is $\sigma^2_e$ when C are the equations multiplied by the residual variance (Mrode's form), 1 for unscaled equations. Equations in skip are left unchanged (constraints). C must be symmetric; row j is read from column j.

Breeding.henderson3 — Function
henderson3(y, X, Z; A = I) -> NamedTuple

Henderson's (1953) Method 3 for a sire model $y = Xb + Zs + e$, $\operatorname{var}(s) = A\sigma^2_s$ (Mrode Sections 17.2–17.4). With $S = I - X(X'X)^-X'$, the sums of squares

  • fixed effects $F = y'X(X'X)^-X'y$,
  • sires corrected for fixed effects $S_s = y'SZ(Z'SZ)^-Z'Sy$, df = rank(Z'SZ),
  • residual $R = y'y - F - S_s$,

are equated to their expectations $E(R) = df_R\sigma^2_e$ and $E(S_s) = df_S\sigma^2_e + \operatorname{tr}(Z'SZA)\sigma^2_s$. Returns the sums of squares, degrees of freedom, ZSZ (whose diagonal holds the effective numbers of daughters) and the estimates σ²e, σ²s.

Breeding.covariance_function — Function
covariance_function(G, t; k = size(G, 1), V = nothing, tmin = minimum(t),
                    tmax = maximum(t)) -> NamedTuple

Fit a covariance function (Kirkpatrick et al., 1990) of Legendre polynomials of order 0:k-1 to a covariance matrix G observed at ages/times t:

\[G \approx \Phi C \Phi'.\]

  • Full order (k = length(t)): $C = \Phi^{-1} G \Phi'^{-1}$ (Mrode Eqn 10.9).
  • Reduced order (k < length(t)): generalized least squares on the $t(t+1)/2$ distinct elements of G, $\check c = (X_s' V^{-1} X_s)^{-1} X_s' V^{-1} \tilde g$, where V is the sampling covariance of the lower-triangle elements (column-major, $G_{11}, G_{21}, …$); V = I (ordinary least squares) if omitted.

Returns C (k × k), Φ, the fitted Ĝ = ΦCΦ', the coefficient matrix T of the covariance function in powers of standardized age ($\Phi = M\Lambda$, $T = \Lambda C \Lambda'$; full order only, else nothing), and Kirkpatrick's goodness-of-fit statistic χ² with df degrees of freedom (χ² = 0 for a full fit).

Breeding.bayes_snp — Function
bayes_snp(y, X, Z; method = :A, ν = 4.012, S = nothing, σ²g = nothing,
          σ²e = nothing, π = 0.3, g0 = 0.0, niter = 10_000, burnin = 3_000,
          nmh = 20, rng = Random.default_rng()) -> BayesResult

Gibbs samplers with residual updating (Legarra and Misztal, 2008) for the SNP model $y = Xb + Zg + e$ (Meuwissen et al., 2001; Habier et al., 2011; Mrode Section 11.7):

  • :A – SNP-specific variances, $\sigma^2_{g_i} | g_i \sim (S + g_i^2)/\chi^2_{\nu+1}$;
  • :B – as A, but $\sigma^2_{g_i} = 0$ with probability π; $(\sigma^2_{g_i}, g_i)$ are sampled jointly with nmh Metropolis–Hastings steps using the prior as proposal;
  • :C – common variance $\sigma^2_g | g \sim (S + g'g)/\chi^2_{\nu+k}$ over the k fitted SNPs; a SNP enters with probability $1 - \pi$ through its indicator's full conditional;
  • :Cpi – as C, with $\pi \sim \mathrm{Beta}(m - k + 1, k + 1)$.

Flat priors are used for b and for $\sigma^2_e$ ($\sigma^2_e = e'e/\chi^2_{n-2}$). S is the scale, by default $\tilde\sigma^2_g(\nu - 2)/\nu$ from the starting SNP variance σ²g, which defaults to $\operatorname{var}(y)/2 / (2\sum p_j q_j)$ with $p$ from Z (taken as uncentred dosages). Starting values: $b = (X'X)^{-1}X'y$, g0 for every SNP, σ²e = var(y) / 2.

Columns of Z are processed in place; the work per iteration is $O(nm)$ and allocation-free.

Breeding.threshold_model — Function
threshold_model(N, X, Z, Kinv, λ; t0 = nothing, zero = Int[], tol = 1e-9,
                maxiter = 100) -> ThresholdResult

Mode of the posterior of thresholds, fixed and random effects for an ordered categorical trait with a probit link (Gianola and Foulley, 1983; Mrode Section 15.2). N is the s × m contingency table of counts (rows: subclasses, columns: ordered categories), X and Z relate subclasses to fixed and random effects, and the random effects have $\operatorname{var}(u) = K\sigma^2_u$ with $\lambda = 1/\sigma^2_u$ (residual variance of the liability is 1).

Each Newton–Raphson (Fisher scoring) round solves Eqn 15.4,

\[\begin{bmatrix} Q & L'X & L'Z \\ X'L & X'WX & X'WZ \\ Z'L & Z'WX & Z'WZ + K^{-1}\lambda \end{bmatrix} \begin{bmatrix} \Delta t \\ \Delta b \\ \Delta u \end{bmatrix} = \begin{bmatrix} p \\ X'v \\ Z'v - K^{-1}\lambda u \end{bmatrix},\]

with Q, L, W, v, p from Eqns 15.7–15.12. zero lists fixed-effect columns constrained to zero. Starting thresholds default to the probit of the cumulative proportions; b = u = 0. Iteration stops when the largest increment is below tol.

Maximizes expected genetic gain $\mathbf{c}'\mathbf{u}$ subject to:

  • $\mathbf{c}'\mathbf{A}\mathbf{c} \le K$, where $K = 2k_t$ is the maximum allowed average relationship among selected parents;
  • $\mathbf{Q}'\mathbf{c} = [\tfrac{1}{2}, \tfrac{1}{2}]'$ (equal total contribution from males and females);
  • $\mathbf{c} \ge \mathbf{0}$.

Arguments

  • ped::DataFrame: Candidate table with columns tmi (EBV or total merit index) and sex (1/true for males, 0/false for females).
  • u::AbstractVector{<:Real}: Vector of candidate EBVs or index values.
  • sex::AbstractVector: Candidate sexes (1/true for males, 0/false for females).
  • A::AbstractMatrix{<:Real}: Symmetric positive definite relationship matrix of the candidates (n × n).
  • K::Real: Upper constraint on $\mathbf{c}'\mathbf{A}\mathbf{c}$.

Returns

  • Vector{Float64}: Optimal parental contribution vector c of length n summing to 0.5 in each sex. If the relationship constraint K cannot be achieved, a warning is issued and the minimum-coancestry contributions are returned.

Breeding.rocs — Function
rocs(
    μ::AbstractVector{<:Real},
    Σ::AbstractMatrix{<:Real};
    Ω::Union{Nothing, AbstractVecOrMat{<:Real}} = nothing,
    sex::Union{Nothing, AbstractVector} = nothing,
    λ::Real = 1.0,

    lb::Union{Real, AbstractVector{<:Real}} = 0.0,
    ub::Union{Real, AbstractVector{<:Real}} = 1.0,
    tol::Real = 1e-9,

Solve the Robust Optimal Contribution Selection (ROCS) problem of Fogg, Ortiz-Cuadros, Pocrnić, Hall, and Gorjanc (2026, Bioinformatics 42(8):btag569):

\[\max_{\mathbf{l} \le \mathbf{w} \le \mathbf{u}} \left( \mathbf{w}'\bar{\boldsymbol{\mu}} - \kappa \sqrt{\mathbf{w}'\boldsymbol{\Omega}\mathbf{w}} - \frac{\lambda}{2} \mathbf{w}'\boldsymbol{\Sigma}\mathbf{w} \right) \quad \text{subject to} \quad \mathbf{M}\mathbf{w} = \mathbf{m}\]

where:

  • $\bar{\boldsymbol{\mu}} = \mathbb{E}(\boldsymbol{\mu} \mid \mathbf{y})$ is the vector of estimated breeding values (EBVs);
  • $\boldsymbol{\Omega} = \operatorname{Var}(\boldsymbol{\mu} \mid \mathbf{y})$ is the prediction error covariance (PEC) matrix (or a vector of prediction error variances, $\operatorname{diag}(\boldsymbol{\Omega})$, e.g. from pev);
  • $\boldsymbol{\Sigma}$ is the genetic relationship (coancestry) matrix among selection candidates (e.g. $\mathbf{A}$ or $\mathbf{G}$).

Four Selection Regimes (Table 2 of Fogg et al., 2026)

  • λ = 0, κ = 0: Classical Truncation Selection (TS)
  • λ = 0, κ > 0: Robust Truncation Selection (RTS)
  • λ > 0, κ = 0: Classical Optimal Contribution Selection (OCS)
  • λ > 0, κ > 0: Robust Optimal Contribution Selection (ROCS)

Arguments

  • μ::AbstractVector{<:Real}: Candidate EBVs or index values of length n.
  • Σ::AbstractMatrix{<:Real}: Symmetric n × n genetic relationship matrix.

Keywords

  • Ω = nothing: Prediction error covariance matrix (n × n) or prediction error variance vector (n). Required when κ > 0.
  • sex = nothing: Optional vector of length n partitioning candidates into two sexes (e.g. 0/1, false/true, or "M"/"F"), enforcing $\sum_{i \in \mathcal{S}} w_i = \tfrac{1}{2}$ and $\sum_{i \in \mathcal{D}} w_i = \tfrac{1}{2}$. If nothing, enforces the single-cohort constraint $\sum_{i=1}^n w_i = 1$.
  • λ::Real = 1.0: Coancestry penalty weight ($\lambda \ge 0$).
  • κ::Real = 0.0: Robustness uncertainty penalty weight ($\kappa \ge 0$).
  • lb = 0.0: Scalar or vector of lower bounds on $\mathbf{w}$ (must be $\ge 0$).
  • ub = 1.0: Scalar or vector of upper bounds on $\mathbf{w}$.
  • tol::Real = 1e-9: KKT optimality tolerance.
  • maxiter::Integer = 200: Maximum outer SQP / variational QP iterations.

Returns

  • ROCSResult: Struct containing w, objective, merit ($\mathbf{w}'\bar{\boldsymbol{\mu}}$), std_error ($\sqrt{\mathbf{w}'\boldsymbol{\Omega}\mathbf{w}}$), coancestry ($\mathbf{w}'\boldsymbol{\Sigma}\mathbf{w}$), λ, κ, iterations, and converged.

Breeding.ROCSResult — Type
struct ROCSResult

Solution of a Robust Optimal Contribution Selection (ROCS), Optimal Contribution Selection (OCS), Robust Truncation Selection (RTS), or Truncation Selection (TS) problem (Fogg et al., 2026, Bioinformatics 42(8):btag569).

Fields

  • w::Vector{Float64}: Optimal candidate contribution proportions (n candidates).
  • objective::Float64: Realized objective value $\mathbf{w}'\bar{\boldsymbol{\mu}} - \kappa\sqrt{\mathbf{w}'\boldsymbol{\Omega}\mathbf{w}} - \tfrac{\lambda}{2}\mathbf{w}'\boldsymbol{\Sigma}\mathbf{w}$.
  • merit::Float64: Expected genetic merit $\mathbf{w}'\bar{\boldsymbol{\mu}}$.
  • std_error::Float64: Standard error of expected genetic merit $\sqrt{\mathbf{w}'\boldsymbol{\Omega}\mathbf{w}}$.
  • coancestry::Float64: Group coancestry $\mathbf{w}'\boldsymbol{\Sigma}\mathbf{w}$.
  • λ::Float64: Penalty weight on group coancestry.
  • κ::Float64: Robustness parameter penalizing uncertainty in expected genetic merit.
  • iterations::Int: Number of outer solver iterations executed.
  • converged::Bool: Whether the KKT optimality tolerance was met.

Supports tuple destructuring (w, objective, merit, coancestry, std_error) = rocs(...).
